## 1. 경기 판정 엔진의 기본 원리

IDOL Manager의 경기 시뮬레이션 엔진은 출전한 아이돌들의 8대 능력치를 바탕으로 틱(Tick) 단위의 정밀한 판정을 거쳐 승패를 가립니다.

- **출전 인원**: 콘텐츠 규정에 따라 1명에서 최대 5명까지 출전합니다.
- **선수당 기본 판정 횟수**: 출전한 아이돌 1인당 정확히 **60회의 판정**을 수행합니다.
  - **주요 판정 (30회)**: 해당 경기 콘텐츠에 지정된 2~3종의 핵심 능력치 중에서 추첨하여 검정합니다.
  - **보조 판정 (30회)**: 주요 능력치를 제외한 나머지 능력치 중에서 매회 무작위로 추첨하여 검정합니다.
- **성공률 계산 공식**:
  - 판정 대상 능력치 점수가 높을수록 주사위 성공 확률이 선형적으로 상승합니다.
  - 피로도가 누적되어 있거나 부상 회복 중인 선수는 페널티가 적용됩니다.

## 2. 5인 무대 배치 및 시각화 UI

경기가 시작되면 양 팀의 아이돌들이 무대 중앙의 대형 **VS** 로고를 중심으로 맞붙는 화려한 배틀 스테이지가 펼쳐집니다.

```
       [ 우리 기획사 무대 ]                  [ 상대 기획사 무대 ]
  ┌─────┐  ┌─────┐  ┌─────┐            ┌─────┐  ┌─────┐  ┌─────┐
  │ 1번 │  │ 2번 │  │ 3번 │            │ 1번 │  │ 2번 │  │ 3번 │  (윗줄 3명)
  └─────┘  └─────┘  └─────┘    VS      └─────┘  └─────┘  └─────┘
      ┌─────┐  ┌─────┐                      ┌─────┐  ┌─────┐
      │ 4번 │  │ 5번 │                      │ 4번 │  │ 5번 │      (아랫줄 가운데 2명)
      └─────┘  └─────┘                      └─────┘  └─────┘
```

### 무대 카드 동적 레이아웃
- **1인 솔로 대결**: 대형 카드로 무대 중앙에 웅장하게 표시됩니다.
- **2~3인 유닛 대결**: 중간 크기의 카드로 가로 정렬됩니다.
- **4~5인 그룹 대결**: 팀마다 **윗줄 3명, 아랫줄 가운데 2명**의 균형 잡힌 다이아몬드 형태로 배치되어 어떤 선수가 활약하는지 한눈에 파악할 수 있습니다.
- **고해상도 썸네일 캐시**: 인물 사진은 원본 파일을 손상시키지 않고 `data/battle_thumbnails/`에 전용 썸네일로 비동기 로딩되어 화면 전환 시 버벅임이 전혀 없습니다.

## 3. 실시간 판정 연출과 시간 구조

- **0.35초 하이라이트 애니메이션**: 판정이 일어나는 순간 카드가 역동적으로 반응합니다.
  - **성공 시**: 테두리가 **초록색**으로 발광하며 `+1 성공` 마크가 떠오릅니다.
  - **실패 시**: 테두리가 **분홍색**으로 깜빡이며 `실패` 텍스트가 표시됩니다.
  - **리더 추가 판정 시**: 1군 리더가 발동하면 보라색 강조 문구와 함께 하단 로그에 리더십 보너스가 실시간 출력됩니다.
- **60개 틱(Tick) 단위 진행**:
  - 여러 선수가 동시 출전한 경기라도 모든 선수가 동시간대에 판정을 받으므로, 화면 전체는 **60개의 기본 틱(0.5초/틱, 총 약 30초)** 동안 진행됩니다.
  - 화면 상단에는 `기본 판정 틱 (X / 60)`과 `개별 판정 (X / 전체 이벤트 수)`가 명확히 구분되어 진행 상황을 알려줍니다.
- **동점 데스매치 연출**: 정규 60틱 종료 후 동점일 경우 10틱 묶음(약 5초) 단위의 데스매치 모드로 즉시 전환됩니다.

## 4. 스킵(건너뛰기)과 관전의 난수 완전 동기화

IDOL Manager의 경기 엔진은 **결정론적 원자적 저장(Atomic Determinism)** 원칙으로 설계되었습니다.

> [!IMPORTANT]
> **스킵을 눌러도 경기 결과나 판정 확률이 절대 바뀌지 않습니다.**
> 1. 플레이어가 [경기 시작]을 누르는 즉시, 시뮬레이션 엔진이 60틱의 모든 판정 주사위와 부상 여부, 최종 점수를 계산하여 SQLite DB에 먼저 안전하게 영구 저장합니다.
> 2. 무대 화면은 이미 확정되어 저장된 이벤트를 0.5초 단위로 순차 재생하는 뷰어(Viewer) 역할을 합니다.
> 3. 따라서 **30초 동안 끝까지 흥미진진하게 관전하든, 1초 만에 [스킵]을 눌러 결과 탭으로 넘어가든 결과는 단 1의 오차도 없이 100% 동일**합니다.

관전 중 언제든지 **[일시정지]**로 멈추어 선수들의 상태를 확인하거나, **[재개]**로 다시 이어보거나, 바쁠 때는 **[스킵]**으로 빠르게 결과를 확인할 수 있습니다.
