## 1. 개요

**IDOL Manager**는 스포츠 경영 시뮬레이션 명작인 *Football Manager (FM)*, *Out of the Park Baseball (OOTP)*의 정밀한 데이터 기반 시뮬레이션 방식을 '아이돌 기획사 경영'에 접목한 Windows PC용 싱글플레이 경영 시뮬레이션 게임입니다.

플레이어는 10개 기획사 리그 중 하나의 기획사 총괄 대표가 되어 가상의 아이돌 인재들을 스카우트하고, 16라운드 창단 드래프트 및 매년 통합 드래프트, 자유계약(FA), 연습생 육성을 통해 최강의 팀을 꾸려나갑니다. 매주 수요일부터 일요일까지 열리는 30종의 방송·공연 콘텐츠 대결에서 승리하고, 상위 4개 팀이 맞붙는 포스트시즌 토너먼트에서 최종 우승 트로피를 들어올리는 것이 궁극적인 목표입니다.

## 2. 게임의 기본 방향

- **싱글플레이 및 공정한 AI**: 플레이어는 10개 기획사 중 1곳을 맡아 운영하며, 나머지 9개 기획사는 플레이어와 완전히 동일한 규칙(자금, 부상, 피로, 계약 등)을 준수하는 전략형 AI가 운영합니다. 난이도 조절을 이유로 AI에게 숨겨진 능력치 버프나 재정 특권을 제공하지 않습니다.
- **철저한 가상 데이터**: 사용자가 지정한 사진 폴더(`assets/idols/`)와 기획사 로고(`assets/agencies/`)를 자유롭게 활용할 수 있지만, 게임 속 인물의 나이, 8대 능력치, 건강, 숨겨진 잠재력(PA), 계약 연봉은 모두 가상으로 무작위 생성됩니다. 실제 인물의 현실 실력이나 사생활은 일절 반영하지 않습니다.
- **표와 텍스트 중심의 높은 가독성**: 화려하지만 반복적인 캐릭터 3D 애니메이션 대신, Windows 환경에 최적화된 맑은 고딕 글꼴과 라벤더·파스텔톤의 명확한 데이터 표를 채택하여 수많은 선수의 스탯과 경기 기록을 빠르게 검색하고 비교 분석할 수 있습니다.
- **31주 / 217일 전용 캘린더**: 실제 현실의 연월일 달력 대신 `시즌 1 · 정규 1주차 · 월요일` 형태의 게임 전용 달력 체계를 따릅니다.

## 3. 한눈에 보는 핵심 규칙

| 구분 | 주요 내용 |
| :--- | :--- |
| **참가 기획사** | 총 10개 기획사 (플레이어 1곳, AI 9곳) |
| **선수단 정원** | 1군 프로 5명, 2군 프로 최대 11명 (프로 총원 최대 16명), 연습생 인원 무제한 |
| **시즌 일정** | 한 시즌 총 31주 (217일): 정규 24주 + 포스트시즌 3주 + 비시즌 4주 |
| **정규 리그 경기** | 기획사당 117경기 (상대 9개 팀과 각 13회 맞대결), 리그 전체 585경기 |
| **8대 능력치** | 보컬, 댄스, 랩, 예능, 외모, 신체, 지성, 리더십 (0~100) |
| **건강 시스템** | 최대 상한 90, 비시즌 1년 경과 시 건강 1씩 감소 (부상 확률 지표) |
| **경기 판정** | 출전자 1인당 60틱 이벤트 판정 (주요 능력치 30회 + 보조 30회) |
| **기획사 재정** | 시작 자금 10억 원, 정규 주간 후원금 1,000만 원, 시즌 종료 보너스 10억 원 |

## 4. 플레이 권장 흐름

1. **창단 준비 (7일)**: 최초 200명의 후보 중 160명을 선발하는 16라운드 스네이크 드래프트를 진행하고, 상위 1~3라운드 지명자와 연봉 계약을 체결합니다.
2. **선수단 편성**: 프로 16명 중 실력과 컨디션이 우수한 5명을 1군으로 선발하고, 1군/2군 리더를 각각 지정합니다.
3. **정규 리그 (24주)**: 매주 월요일 주간 상대 및 30종 콘텐츠 정보를 확인하고, 수요일부터 토요일까지 정규 경기를 치르며, 4주마다 일요일 특별전에 참가합니다.
4. **포스트시즌 (3주)**: 정규 리그 상위 4개 팀이 3판 2선승제 토너먼트를 치러 시즌 최종 우승 기획사를 가립니다.
5. **비시즌 (4주)**: 시즌 정산 및 개인 시상식을 진행하고, 신규 유입 70명에 대한 3라운드 통합 드래프트와 FA 영입, 연습생 프로 데뷔를 완료합니다.
