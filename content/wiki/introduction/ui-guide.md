## 1. 인터페이스 혁신 개요

IDOL Manager는 수많은 선수 데이터와 경기 기록을 한눈에 관리해야 하는 시뮬레이션 게임의 특성을 살려, 사용자 맞춤형 **도킹 패널 워크스페이스 시스템(`dock_workspace.py`)**과 모바일·피벗 모니터 환경을 위한 **900×1600 세로형 화면 모드(`portrait_layout.py`)**를 지원합니다.

플레이어는 각자의 모니터 환경(단일 모니터, 듀얼 모니터, 세로 피벗 모니터, 태블릿 PC 등)에 맞춰 화면 배치를 자유자재로 커스터마이징할 수 있습니다.

---

## 2. 도킹 패널 시스템 조작법

선수단 명단, 드래프트 후보표, 경기 관전 무대, 판정 기록, 프로필 상세 정보 등 게임 내의 모든 표와 데이터 패널은 도킹이 가능합니다.

```
┌──────────────────────────────────────────────┐
│  [선수단 명단 패널]  │  [선수 상세 프로필 패널]  │
│                     │                        │
│                     │                        │
│                     │                        │
├─────────────────────┴────────────────────────┤
│           [주간 일정 및 기록 요약 패널]            │
└──────────────────────────────────────────────┘
          ▲ 보라색 경계선을 드래그하여 비율 조절
```

### 핵심 조작 가이드

- **보라색 경계선 드래그**: 패널 사이에 표시되는 은은한 보라색 경계선을 마우스로 끌어 상하 또는 좌우 분할 비율을 자유롭게 늘리거나 줄일 수 있습니다.
- **제목줄 드래그 (위치 이동)**: 패널 상단의 제목줄을 잡고 드래그하여 원하는 위치로 옮길 수 있습니다. 다른 패널의 가장자리에 놓으면 나란히 배치되고, 패널 중앙에 놓으면 **탭(Tab) 형태**로 묶여 탭 전환 방식으로 볼 수 있습니다.
- **패널 분리(Float) 기능 (듀얼 모니터 활용)**:
  - 패널 제목줄을 **더블클릭**하거나 제목줄 우측의 **분리 버튼(⧉)**을 누르면 해당 패널이 독립된 윈도우 창으로 튀어나옵니다.
  - 분리된 창은 모니터 다른 쪽이나 보조 모니터로 옮겨서 크게 띄워둘 수 있어, 한쪽 화면에는 경기 무대를 띄우고 다른 쪽 화면에는 실시간 판정 기록표를 띄우는 멀티태스킹이 가능합니다.
- **원래 위치로 도킹 복원**: 분리된 창의 제목줄을 **우클릭 → [원래 작업영역으로 도킹]**을 선택하면 즉시 본래 화면의 자리로 복귀합니다.
- **패널 닫기 및 복원**:
  - 패널 제목줄의 **X** 버튼을 누르면 화면에서 숨겨집니다. (데이터는 안전하게 보존되며 표 화면만 숨겨집니다.)
  - 화면 상단의 **[패널 배치 ▾]** 메뉴를 누르면 **'숨긴 패널 다시 표시'** 또는 **'기본 배치로 복원'**을 선택하여 언제든지 초기 레이아웃으로 되돌릴 수 있습니다.

### 레이아웃 설정 보존 (`data/ui_layout.ini`)
- 사용자가 조절한 각 패널의 크기, 도킹 위치, 탭 결합 상태, 분리 창 위치는 `data/ui_layout.ini` 파일에 실시간으로 자동 저장됩니다.
- 게임을 종료하고 다시 실행해도 내가 맞춰둔 완벽한 작업 환경이 그대로 유지됩니다.

## 3. 900×1600 스마트폰 세로형 모드

스마트폰처럼 긴 세로 화면을 선호하거나 피벗 모니터, 좁은 창 크기(창 너비 1000px 이하)에서 플레이하는 사용자를 위해 특화된 세로형 UI 레이아웃을 제공합니다.

### 세로 모드 핵심 편의 기능

1. **상단 화면 이동 선택기**:
   - 가로가 좁아지면 왼쪽 사이드바 메뉴가 자동으로 상단의 직관적인 **[화면 이동 ▾]** 드롭다운 선택기로 전환되어 본문 표시 영역을 최대한 넓게 확보합니다.
2. **표 행 페이징 (`◀ / ▶`)**:
   - 수십 명의 긴 선수 명단을 세로 스크롤 없이 깔끔하게 넘겨볼 수 있도록 표 하단에 페이지 이동 버튼이 제공됩니다.
3. **열 묶음 전환 (`정보 1/N`)**:
   - 한 선수의 수많은 데이터(8대 스탯, 나이, 계약 기간, 연봉, 통산 성적 등)가 한 화면에 다 들어가지 않을 때, `정보 1/N` 버튼을 누르면 사진과 이름 열은 고정한 채 능력치 묶음 ↔ 계약 묶음 ↔ 통계 묶음으로 매끄럽게 전환됩니다.
4. **선택 상세 팝업**:
   - 표에서 특정 선수를 선택하고 **[선택 상세]**를 누르면, 공개된 모든 열의 상세 정보를 깔끔한 카드 페이지 형태로 한 번에 확인할 수 있습니다.
5. **5인 경기 관전 무대 세로 최적화**:
   - 세로 모드에서도 경기 목록과 무대 영역이 조화롭게 자동 재배치되어 윗줄 3명, 아랫줄 2명의 무대 카드가 잘림 없이 선명하게 표시됩니다.

> [!TIP]
> 일반 데스크톱 PC에서도 게임 창 너비를 1000px 이하로 좁히면 자동으로 세로형 최적화 레이아웃이 적용됩니다. 웹 서핑이나 다른 작업을 하면서 화면 한구석에 띄워두고 플레이하기에 매우 편리합니다.
