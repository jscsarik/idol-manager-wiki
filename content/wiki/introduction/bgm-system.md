## 1. BGM 시스템 개요

IDOL Manager는 기획사 경영의 몰입감을 극대화하기 위해 **상황별 동적 BGM(Background Music) 시스템**을 탑재하고 있습니다.

게임 내 배경음악은 평상시 기획사를 경영하고 선수단을 관리하는 **일반(Default) 모드**와, 손에 땀을 쥐는 5인 무대 대결이 펼쳐지는 **배틀(Battle) 모드**로 완전 분리되어 상황에 맞춰 자동으로 음악이 전환됩니다.

별도의 복잡한 외부 코덱 설치 없이 Windows 네이티브 멀티미디어 엔진(`QUrl.fromLocalFile()`)을 통해 고음질 무손실 재생을 지원합니다.

---

## 2. 음악 폴더 경로 및 파일 규격

게임 클라이언트가 위치한 루트 폴더 아래 `assets/audio/bgm/` 디렉토리에 음악 파일들이 분류되어 있습니다.

```text
[IDOL Manager 설치 폴더]
└── assets/
    └── audio/
        └── bgm/
            ├── default/   (일반 화면 음악: 메뉴, 명단, 재정, 일정, 드래프트 등)
            └── battle/    (경기 관전 화면 음악: 정규 경기 무대, 특별전 대결 등)
```

### 지원 파일 형식 및 특징
- **지원 확장자**: `.mp3`, `.wav` (대소문자 무관)
- **파일명 지원**: 순수 한글, 영문, 숫자, 특수문자, 띄어쓰기(공백)를 완벽 지원합니다.
- **검색 방식**: 폴더 바로 아래의 파일들을 직접 탐색하며, 하위 폴더는 재귀 검색하지 않습니다.
- **기본 수록곡**: 일반 18곡, 배틀 13곡이 번들로 기본 내장되어 있습니다.

## 3. 나만의 커스텀 BGM 추가하기 (꿀팁)

플레이어는 자신이 좋아하는 실제 K-POP 아이돌 음원이나 매니지먼트 분위기에 어울리는 음악을 직접 게임에 넣어서 즐길 수 있습니다!

1. 추가하고 싶은 음악 파일(MP3 또는 WAV)을 준비합니다.
2. 일반 경영 화면에서 듣고 싶다면 `assets/audio/bgm/default/` 폴더에 복사합니다.
3. 경기 관전 시 긴장감을 더하고 싶다면 `assets/audio/bgm/battle/` 폴더에 복사합니다.
4. 게임 화면 상단의 **♪ BGM → [음악 목록 새로고침]** 버튼을 누릅니다.
5. 게임을 재시작할 필요 없이 즉시 새 음악이 셔플 재생 목록에 반영됩니다.

> [!TIP]
> 음악 파일 이름은 자유롭게 작성해도 상관없습니다. 개수 제한이 없으므로 수십 곡 이상의 음원을 넣어 나만의 플레이리스트를 구성할 수 있습니다.

## 4. 상단 BGM 제어 패널 조작법

게임 메인 윈도우 상단 타이틀바 우측의 **♪ BGM** 버튼을 클릭하면 편리한 미니 오디오 컨트롤러가 펼쳐집니다.

| 기능 | 설명 | 단축키 / 동작 |
|---|---|---|
| **BGM 켜기 / 끄기** | 전체 배경음 활성화 여부를 토글합니다. 끄면 오디오 재생 자원을 즉시 반환합니다. | 체크박스 토글 |
| **음소거** | 재생 진행 위치는 유지한 채 사운드 출력만 0으로 음소거합니다. | 음소거 체크 |
| **일시정지 / 재생** | 현재 재생 중인 곡의 위치에서 멈추거나 다시 이어 재생합니다. | 클릭 시 즉시 토글 |
| **볼륨 슬라이더** | 0%부터 100%까지 볼륨을 미세 조정합니다. (기본값: 적정 볼륨 권장) | 슬라이더 드래그 |
| **다음 곡 (▶▶)** | 현재 카테고리의 다음 셔플 곡으로 즉시 건너뜁니다. | 다음 곡 버튼 |
| **음악 목록 새로고침** | 폴더에 새로 넣거나 삭제한 음악 파일을 즉시 재스캔합니다. | 새로고침 버튼 |

## 5. 동적 BGM 전환 구조 및 설정 보존

### 상황별 자동 음악 전환
- **경영 및 일상 화면**: 메뉴, 선수단 명단, 선수 시장, 회계 장부, 일정표, 기록실 등 모든 일반 화면 간을 이동할 때는 **현재 재생 중인 일반 음악이 끊기지 않고 부드럽게 이어집니다.** 화면을 이동할 때마다 곡이 처음부터 다시 켜지는 끊김 현상이 없습니다.
- **경기 관전 탭 진입**: 정규 경기 또는 특별전의 **[경기 진행]** 탭(무대 관전 화면)에 진입하는 순간, 자동으로 **배틀 BGM**으로 전환되어 박진감 넘치는 무대 사운드가 재생됩니다.
- **경기 종료 후 복귀**: 경기 관전이 끝나고 결과 탭을 확인하거나 다른 메뉴로 나가면 다시 원래의 차분한 일반 경영 BGM으로 자동 복귀합니다.

### 설정 저장 방식 (`data/bgm_settings.json`)
- 사용자가 조절한 볼륨 크기, BGM 켜기/끄기, 음소거 상태는 게임 세이브 파일(SQLite DB)이 아닌 별도의 `data/bgm_settings.json` 파일에 원자적으로 저장됩니다.
- 따라서 **새 게임을 시작하거나 다른 세이브 슬롯을 불러와도 플레이어가 맞춰둔 음악 환경설정은 그대로 보존**됩니다.
