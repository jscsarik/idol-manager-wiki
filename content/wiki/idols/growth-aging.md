## 1. 개요

IDOL Manager의 선수 성장은 매일 조금씩 오르는 방식이 아니라, 지난 일주일간의 실전 경기와 훈련 성과를 모아 **매주 월요일 정규 정산**에서 일괄 처리됩니다.

성장은 선수의 신분(1군 / 2군 / 연습생)에 따라 서로 다른 메커니즘을 따르며, 개별 잠재력 상한(PA)을 절대 초과할 수 없습니다.

## 2. 신분별 기본 성장 규칙

### [1군 기본 성장: 실전 경험 기반]
- 지난주 경기에서 개별 주요 능력치 판정의 **성공 횟수**를 집계합니다.
- **성공 1위 능력치**: 확률 **(100 - 현재 능력치) × 3%** (최대 100%)로 +1 상승 시도.
- **성공 2위 능력치**: 확률 **(100 - 현재 능력치) × 2%** (최대 100%)로 +1 상승 시도.
- 위 두 능력치는 하락 후보에서 완전 제외됩니다.
- **사용 빈도가 가장 적은 스탯 1·2위**: 1위는 (현재 능력치)% 확률로 -1, 2위는 (현재 능력치 ÷ 2)% 확률로 -1 하락 위험.
- **출전 취소 페널티**: 해당 주에 부상을 당했거나 3일 이상 연속 출전한 선수는 상승 판정 2회가 전면 취소됩니다 (감소 판정은 유지).
- **무출전 페널티**: 1군에 등록되었으나 한 주 동안 단 1경기도 출전하지 못한 선수는 서로 다른 무작위 능력치 2개가 자동으로 각각 -1 차감됩니다.

### [2군 기본 성장: 안정적 훈련]
- 매주 서로 다른 무작위 능력치 2개를 선정해 훈련 판정을 진행합니다. (상승 확률: (100 - 현재 능력치) × 2%, 하락 확률: 현재 능력치 ÷ 2%)
- **2군 기본 훈련비**: 선수당 주 10만 원 발생.
- **선택적 집중 훈련**: 선수당 주 15만 원 추가 지출 시, 지정 능력치는 감소 없이 기본 (100 - 현재 능력치) × 2%, 코치 추천 강점인 경우 **(100 - 현재 능력치) × 3.5%** 확률로 +1 상승합니다.
- **2군 리더 효과**: 2군 리더는 매주 **(리더십 점수 ÷ 2)%** 확률로 2군 선수 1명에게 스탯 +1 보너스를 부여할 수 있습니다.

### [연습생 기본 성장: 무감소 안전 육성]
- 매주 서로 다른 4개 능력치를 무작위 선정.
- 각 능력치마다 **(100 - 현재 능력치) × 1.5%** 확률로 +1 상승 판정.
- **연습생은 일반 훈련에서 능력치 하락(감소)이 절대 발생하지 않습니다.**

## 3. 잠재력 격차에 따른 '추가 급성장' (전 신분 공통)

현재 8개 능력치 평균(CA)과 숨겨진 잠재력(PA)의 차이를 **잠재력 격차(PA - CA)**라고 합니다.
모든 선수는 신분과 무관하게 매주 월요일마다 **2번의 독립적인 추가 성장 판정**을 받습니다.

| 잠재력 격차 (PA - CA) | 판정 1회당 성공 확률 | 주간 기대 성장치 |
| :--- | :--- | :--- |
| **30점 이상 (초대형 유망주)** | **판정당 50%** | 매주 최대 +2점 폭풍 성장 가능 |
| **20점 ~ 29점 (대형 유망주)** | **판정당 40%** | 높은 확률로 +1~+2점 성장 |
| **10점 ~ 19점 (일반 유망주)** | **판정당 25%** | 꾸준한 성장 |
| **1점 ~ 9점 (잠재력 한계 임박)** | **판정당 10%** | 완만한 성장 |
| **0점 이하 (완성형 / 상한 도달)** | **0% (성장 없음)** | 추가 성장 불가 (잠재력 도달) |

## 4. 노화 감소 (Aging)

정규 시즌 짝수 주차(2, 4, 6, 8, ... 24주차) 월요일에는 나이 든 베테랑 선수들에게 **노화 감소**가 발생합니다 (시즌당 총 12회 정산).

- **만 27세 이하**: 노화 감소 전혀 없음
- **만 28 ~ 29세**: 2주마다 무작위 능력치 1개 **-1점** (연간 총 12점 하락)
- **만 30세 이상**: 2주마다 서로 다른 능력치 2개 각 **-1점** (연간 총 24점 하락)
- 능력치는 0점 아래로 내려가지 않으며, 뛰어난 활약으로 얻은 성장치와 상쇄될 수 있습니다.
