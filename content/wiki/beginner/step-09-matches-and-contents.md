## 1. 정규 경기 60회 판정 엔진

IDOL Manager의 공식 경기는 당일 지정된 콘텐츠(맵)와 필요 인원에 맞춰 진행됩니다.

* **기본 판정 구조**:
  * 출전한 아이돌 **1명당 기본 60회의 판정**을 수행합니다.
  * **주요 능력치 판정 30회**: 콘텐츠의 핵심 능력치(3개면 각 10회씩, 2개면 각 15회씩)로 판정합니다.
  * **보조 능력치 판정 30회**: 주요 능력치를 제외한 나머지 능력치 중에서 매 판정마다 무작위로 하나를 골라 판정합니다.
* **성공 확률 원리**:
  * 해당 능력치 점수가 80점인 선수는 판정 시 기본적으로 약 80%의 성공 확률을 갖습니다. (연속 출전 피로 페널티가 있을 경우 능력치가 일시 감산되어 적용됩니다.)
* **승패 결정**:
  * 팀 전체 출전 선수의 성공 횟수를 모두 합산하여, **더 많은 성공 득점을 기록한 기획사가 승리**합니다. (승리 시 리그 승점 +1점, 패배 시 +0점)

## 2. 1군 리더십 보너스와 동점 데스매치

### 👑 리더 보너스 (추가 판정 2회)
* 지정된 **1군 리더가 경기에 직접 출전**하면, 기본 60회 판정 외에 **리더십 판정 2회가 별도로 추가**되어 팀의 성공 점수에 합산됩니다.

### ⚔️ 동점 시 데스매치 (Deathmatch)
* 60회 판정 종료 후 양 팀의 총 성공 득점이 동점이라면 무승부로 끝나지 않고 **데스매치 연장전**에 돌입합니다.
* 양 팀에서 대표 아이돌 1명씩을 선정하여, 해당 콘텐츠의 주요 능력치로 **각 10회씩 추가 판정**을 실시합니다.
* 10회 후에도 동점이면 승부가 날 때까지 10회씩 추가 판정을 무한 반복합니다.

> ⚠️ **2군 긴급 대체 출전 불가**:  
> 기본 정규 경기 당일에는 2군 선수를 긴급 대체로 투입할 수 없습니다. 5명 출전 콘텐츠에 1군 중 건강한 선수가 4명뿐이라면 4명만으로 경기를 치러야 하며, 출전 가능 선수가 0명이면 몰수패 처리됩니다.

## 3. 대표적인 방송 콘텐츠 30종 요약

시즌 전체 585경기는 30종의 콘텐츠에 골고루 배정됩니다. (15종은 각 20회, 15종은 각 19회 등장)

| 콘텐츠 | 주요 능력치 | 필요 인원 |
|---|---|---|
| **음악방송** / **단독콘서트** | **보컬 / 댄스 / 랩** | 5명 |
| **광고촬영** / **화보촬영** / **패션 행사** | **외모 / 신체** | 1~3명 |
| **유튜브** / **토크쇼** / **게임 방송** | **지성 / 예능** | 1~3명 |
| **팬싸인회** | **외모 / 리더십 / 예능** | 3~5명 |
| **댄스 챌린지** / **스트릿 댄스** | **댄스 / 신체** | 1~3명 |
| **음원발매** | **보컬 / 랩 / 지성** | 5명 |
| **연말시상식** (21~24주차 한정) | **보컬 / 댄스 / 외모** | 5명 |

## 4. 4주 주기 특별전 6회

정규 **4·8·12·16·20·24주차 일요일**에는 일반 정규 경기 대신 리그 10개 팀이 맞붙는 특별전이 열립니다.

* **출전 선수단**: 건강한 1군과 필요한 2군을 합쳐 기획사당 **최대 10명** 출전 (선수당 30회 판정: 주요 15회 + 보조 15회)
* **그룹 분할**: 상위 그룹(1~5위) 5자 대결, 하위 그룹(6~10위) 5자 대결
* **승점 변동**:
  * 상위 그룹 1위 +2점, 2위 +1점, 3위 0점
  * 하위 그룹 5위는 -2점 감점!
  * 상위 그룹 4·5위와 하위 그룹 1·2위는 후속 4자 대결을 치르며, 하위 팀이 1위 시 +2점, 상위 팀이 4위 시 -2점이 부여됩니다.
